#🎞**Мультфильм**
---

📃**Описание**

Программа демонстрирует принцип создания простой покадровой анимации. В рисованных мультфильмах иллюзия движения создаётся последовательной сменой кадров, каждый из которых фиксирует очередное положение движущегося объекта. В данной программе этот принцип используется для создания анимации человечка, который выполняет различные действия:

- 🚶‍♂️идёт
- 🏃‍♂️бежит
- 🧎‍♂️приседает
- 🚩подаёт сигнал флажком

Каждое движение состоит из последовательности кадров с немного изменённым положением частей тела. При быстрой смене кадров возникает иллюзия движения
